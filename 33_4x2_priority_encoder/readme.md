# 4×2 Priority Encoder — Verilog RTL

## Overview

A 4×2 Priority Encoder is a combinational circuit that converts four input lines into a 2-bit binary output.

Unlike a normal 4×2 Encoder, a Priority Encoder can handle multiple inputs being HIGH at the same time by assigning priority to the inputs.

Priority order used in this project:

D3 > D2 > D1 > D0

D3 has the highest priority and D0 has the lowest priority.

A valid output `V` is also used to indicate whether any input is active.
